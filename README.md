# FnTube

FnTube 是一个运行在飞牛 NAS 上的媒体刮削工具，使用飞牛影视作为媒体库和媒体信息管理服务，使用 MetaTube 搜索影片信息，并提供自动刮削、手动编辑、刮削记录和计划任务等功能。

## 功能概览

- 浏览飞牛影视媒体库和媒体条目
- 查看媒体详情、播放信息和媒体文件
- 使用媒体文件名作为 MetaTube 搜索关键词
- 手动搜索并选择 MetaTube 影片信息
- 编辑标题、简介、日期、评分、类型、封面、背景图和演职员信息
- 执行单个媒体条目的重新刮削
- 创建按媒体库运行的自动刮削计划
- 查看、筛选和删除刮削记录
- 对刮削记录按番号进行模糊查询
- 根据番号后缀自动添加封面徽标：
  - `-C`、`-CH`：添加 `c.png`
  - `-U`：添加 `u.png`
  - `-UC`：添加 `uc.png`

## 一、安装飞牛应用

### 1. 准备安装包

获取 `FnTube.fpk` 安装包。通过应用中心安装时，建议使用递增版本号，例如 `1.0.0`、`1.0.1`、`1.0.2`，避免飞牛将同版本安装包识别为重复版本。

### 2. 安装方式

在飞牛 NAS 中打开应用中心，选择本地安装，上传 `FnTube.fpk` 并完成安装。

安装完成后，应用通常以 `FnTube` 用户运行，应用数据保存在飞牛应用数据目录中。应用的数据库和日志不会放在项目源码目录中。

### 3. 打开 FnTube

在飞牛桌面打开 FnTube 应用。如果应用图标或页面仍显示旧内容，可以依次尝试：

1. 完全关闭 FnTube 页面；
2. 刷新浏览器页面或清理浏览器缓存；
3. 从飞牛桌面重新打开应用；
4. 确认安装包版本号已经更新；
5. 必要时停止应用后重新启动。

## 二、配置飞牛影视

进入 FnTube 的“飞牛影视配置”页面，填写以下内容。

### 服务端地址

填写飞牛影视 API 地址，例如：

```text
http://127.0.0.1:5666/v
```

如果飞牛影视运行在其他地址或端口，请按实际部署地址填写。地址应包含飞牛影视 API 使用的 `/v` 路径。

### 用户名

填写飞牛影视登录用户名。该账号需要有读取媒体库、读取媒体信息以及修改媒体信息的权限。

### 密码

填写对应的飞牛影视登录密码。

### 访问码

如果飞牛影视启用了访问码，填写访问码；未启用访问码时留空。

### 外网播放地址

用于生成外部播放链接，可选。例如：

```text
https://your-domain.example.com:5666/v
```

如果只在内网使用，可以留空。该地址与飞牛影视服务端地址可以不同。

### 同步媒体库

点击“加载媒体库列表”获取飞牛影视中的媒体库，然后选择需要同步的媒体库。

- 选择“全部媒体库”：同步所有媒体库；
- 选择指定媒体库：只同步选中的媒体库；
- 不需要的媒体库可以不勾选。

填写完成后，点击“测试连接”确认连接正常，再点击“保存配置”。

### 配置建议

1. 优先使用 NAS 本机地址连接飞牛影视，避免额外的反向代理问题；
2. 确认 FnTube 运行用户能够访问飞牛影视服务；
3. 如果测试失败，先检查地址、端口、用户名、密码和访问码；
4. 如果能连接但加载不到媒体库，检查该账号的媒体库访问权限。

## 三、配置 MetaTube

进入“MetaTube 配置”页面。

### 服务地址

填写 MetaTube 服务地址，例如：

```text
http://127.0.0.1:8081
```

填写到 MetaTube 服务根地址即可，不需要手动拼接 `/v1/movies/search` 等接口路径。

### API Token

如果 MetaTube 开启了 Token 鉴权，填写 API Token；未启用 Token 时留空。

点击“测试连接”，确认 FnTube 可以访问 MetaTube 服务。配置 Token 时，测试还会验证 Token 是否有效。

### 翻译设置

FnTube 支持以下翻译模式：

- 不翻译：不调用翻译服务；
- 翻译标题：只翻译影片标题；
- 翻译简介：只翻译影片简介；
- 翻译标题和简介：同时翻译标题与简介。

可选择的翻译引擎包括：

- 百度翻译：填写 APP ID 和 Secret Key；
- DeepL：填写 API Key；
- Google 翻译：填写 Google Cloud Translation API Key；
- Google Free：无需额外密钥；
- OpenAI：填写 API Key、模型和可选 Base URL。

翻译配置只在选择对应引擎后填写。完成后点击“保存配置”。

## 四、浏览媒体库和搜索影片

### 浏览媒体库

进入“媒体库”页面，点击媒体库卡片即可进入媒体条目列表。媒体条目的封面比例会根据飞牛影视媒体库布局设置自动适配。

媒体库页面支持按媒体标题搜索，并可以使用刷新按钮重新加载媒体库。

### 查看媒体详情

点击媒体条目可以打开详情窗口，查看标题、简介、日期、评分、封面、背景图、演员和媒体文件等信息。

### 按文件名搜索 MetaTube

FnTube 会通过飞牛影视媒体流接口获取媒体的第一个文件名，并去掉最后一个文件扩展名作为 MetaTube 搜索关键词。例如：

```text
ABC-123.mp4 -> ABC-123
```

编辑窗口和详情窗口均使用该规则。打开搜索窗口后，可以直接修改关键词并重新搜索，以处理文件名与 MetaTube 番号不一致的情况。

### 选择搜索结果

在 MetaTube 搜索结果中选择正确的影片，FnTube 会将影片详情带回编辑窗口。确认信息无误后保存到飞牛影视。

## 五、手动刮削

在媒体条目列表或刮削记录页面可以执行重新刮削。

手动刮削的大致流程如下：

1. 获取媒体文件名；
2. 使用文件名搜索 MetaTube；
3. 获取影片详情；
4. 下载封面和背景图；
5. 搜索并创建演职员信息；
6. 根据翻译配置翻译标题或简介；
7. 将处理后的媒体信息写回飞牛影视；
8. 写入刮削记录。

### 封面徽标

当搜索关键词以指定后缀结尾时，FnTube 会在封面左上角添加徽标：

| 关键词后缀 | 徽标 |
| --- | --- |
| `-C`、`-CH` | `c.png` |
| `-U` | `u.png` |
| `-UC` | `uc.png` |

后缀判断不区分大小写。徽标会按原始比例缩放，宽度和高度均不会超过封面对应尺寸的一半，然后上传合成后的封面。

## 六、配置刮削计划

进入“刮削计划任务”页面，点击“新建任务”。

### 任务名称

填写便于识别的名称，例如：

```text
每日电影库刮削
```

### 媒体库

选择需要自动刮削的媒体库。媒体库需要先在“飞牛影视配置”页面加载成功。

### 扫描频率

填写执行间隔，单位为分钟。支持范围为 `1` 到 `10080` 分钟。

常用设置示例：

- `60`：每小时执行一次；
- `360`：每 6 小时执行一次；
- `1440`：每天执行一次。

### 启用状态

- 开启：调度器会按设置的时间间隔自动执行任务；
- 关闭：保留任务配置，但不会自动执行。

保存任务后，可以在任务列表中执行以下操作：

- “执行”：立即运行一次任务；
- “编辑”：修改任务名称、媒体库、间隔或启用状态；
- “删除”：删除任务；
- “运行记录”：查看任务每次运行的统计结果。

同一个任务已经运行时，不能重复启动；请等待当前运行完成。

## 七、查看刮削记录

进入“刮削记录”页面可以查看每个媒体条目的刮削结果。

记录包含：

- 番号；
- 标题；
- 刮削方式（自动或手动）；
- 当前状态；
- 刮削时间；
- 重新刮削和删除操作。

### 按番号查询

在页面右上角的搜索框输入完整或部分番号，点击“查询”或按回车键，即可进行模糊查询。

例如输入：

```text
ABC
```

可以匹配包含 `ABC` 的记录。清空输入框后再次查询，即可恢复显示全部记录。

### 状态说明

- 进行中：任务正在处理；
- 成功：刮削流程成功完成；
- 失败：刮削过程中出现错误；
- 完成：记录已完成对应处理。

点击状态可以查看具体步骤和错误信息。点击标题可以打开对应媒体的详情窗口。

## 八、常见问题

### 1. 测试飞牛影视连接失败

检查以下项目：

- 服务端地址是否正确，是否包含 `/v`；
- NAS 上对应端口是否开放；
- 用户名和密码是否正确；
- 访问码是否填写正确；
- FnTube 运行用户是否能够访问该地址。

### 2. MetaTube 搜索不到结果

建议按以下顺序排查：

1. 在 MetaTube 配置页测试连接；
2. 确认 API Token 有效；
3. 打开搜索弹窗检查实际搜索关键词；
4. 手动修改关键词后重新搜索；
5. 确认文件名中的番号格式与 MetaTube 数据源一致。

### 3. 封面下载失败

可能原因包括：

- MetaTube 返回的图片地址不可访问；
- NAS 网络无法连接图片域名；
- 图片服务器证书链不完整；
- 返回的图片格式无法解析。

对于部分证书链异常的图片地址，FnTube 会在标准证书校验失败时进行兼容性回退。如果仍然失败，请检查刮削记录中的错误信息和应用日志。

## 九、本地开发与构建

### 环境要求

- Go 1.22 或更高版本；
- Node.js；
- pnpm；
- 飞牛 `fnpack` 打包工具（仅打包 FPK 时需要）。

### 启动后端

Windows 本地开发时，后端默认监听 `http://localhost:8090`：

```powershell
cd backend
go run .
```

### 启动前端

```powershell
cd frontend
pnpm install
pnpm run dev
```

Vite 开发服务器会将 `/api` 请求代理到本地后端 `http://localhost:8090`。

### 构建后端

```powershell
cd backend
$env:CGO_ENABLED='0'
$env:GOOS='linux'
$env:GOARCH='amd64'
go build -o "..\app\server\fntube" .
```

### 构建前端

```powershell
cd frontend
pnpm run build
```

前端构建产物会输出到 `app/www`。

### 打包 FPK

在项目根目录执行：

```powershell
fnpack build --directory "d:\Tools\fntube"
```

成功后会在项目根目录生成：

```text
FnTube.fpk
```

## 十、数据与日志

FnTube 使用 SQLite 保存配置、刮削记录、刮削计划和任务运行记录。飞牛环境下数据目录由 `TRIM_PKGVAR` 决定，常见路径为：

```text
/vol2/@appdata/FnTube
```

应用日志通常位于：

```text
/vol2/@appdata/FnTube/info.log
```

请在提交问题时同时提供：

- FnTube 版本；
- 飞牛系统版本；
- 相关页面的操作步骤；
- 刮削记录中的错误信息；
- `info.log` 中对应时间段的日志。

提交日志前请移除密码、Token、访问码和其他敏感信息。
